One line of weather for Drizzlemere, a city that does not exist: grey skies, a 60% chance of rain, and a bus shelter that leaks exactly where you stand. It keeps the rhythm of a real broadcast forecast, bent just enough to make a bored commuter smile at the bus stop.

## Run it

```sh
node main.ts
```

The program writes the forecast to `/output/entry.txt`, one line of at most 140 characters.
